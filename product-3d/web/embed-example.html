mioren — 3D Ürün Görüntüleyici (gömme örneği)

Aşağıdaki görüntüleyici bir <iframe> ile gömülüdür. Aynı kodu sitenizin ürün sayfasına yapıştırıp web/ klasörünü sunucunuza yüklemeniz yeterli.

Gömme kodu:

<iframe
  src="/product-3d/web/index.html"
  style="width:100%; aspect-ratio:4/5; max-height:80vh; border:0; border-radius:18px;"
  title="mioren 3D ürün görüntüleyici"
  loading="lazy"
  allowfullscreen>
</iframe>

Shopify / WordPress / Wix: "Özel HTML" (Custom HTML / Embed) bloğuna yukarıdaki kodu yapıştırın. src yolunu, web/ klasörünü yüklediğiniz gerçek adrese göre güncelleyin.
